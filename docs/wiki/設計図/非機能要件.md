## 対応 Python バージョン

### 超過時の挙動

3.12 未満のランタイムで起動した場合はエラーで停止する。
古い構文へフォールバックして動かすことはしない（挙動の差分がテストで検出できなくなるため）。

### 内訳

| 区分 | 値 | 補足 |
| --- | --- | --- |
| 実行基盤の提供 | Python 3.12 | 構成要件で確定した言語・バージョン |
| 追加パッケージ | なし | 標準ライブラリのみで完結させる |
| アプリの決定値 | Python 3.12 以上 | 下限のみを固定し、上限は設けない |
