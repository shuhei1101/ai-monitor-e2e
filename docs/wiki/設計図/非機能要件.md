## 対応 Python バージョン

### 超過時の挙動

対応外のバージョンで起動した場合はエラーにして終了する。
動くかどうかを実行時に判定させず、起動時点で弾く。

### 内訳

| 区分 | 値 | 補足 |
| --- | --- | --- |
| 外部の下限 | Python 3.12.0 | 構成要件で指定されたバージョン |
| 外部の上限 | Python 3.13.0 未満 | 3.13 での動作は未検証 |
| アプリの決定値 | Python 3.12 以上 3.13 未満 | 実行を許可する範囲 |

## 同時実行プロセス数

### 超過時の挙動

2 つ目のプロセスが書き込もうとした時点で `sqlite3.OperationalError` になり、そのプロセスは異常終了する。
リトライも待機もせずに落とす。
同時実行は想定していない使い方なので、黙って待たせると「動いているが反映されない」状態を作ることになる。

### 内訳

| 区分 | 値 | 補足 |
| --- | --- | --- |
| 外部の上限 | 読み込みは複数プロセス / 書き込みは 1 プロセス | SQLite のファイルロックによる直列化 |
| アプリの決定値 | 1 プロセス | 読み書きとも同時に 1 プロセスだけを許可する |
