# 非機能要件

外部コンポーネントの制約を踏まえて、タスク管理ツールが守る値を決める。

外部システムを持たない構成のため、実行基盤（Python 3.12）の公開仕様から引ける行と、外部制約を持たない自主基準の行だけを立てている。

## 実行ランタイム

### 超過時の挙動

サポート対象外のランタイムでは起動時にエラーとして終了する。
動く範囲で黙って動かすと、標準ライブラリの差分に起因する不具合が実行時まで露見しない。

### 内訳

| 区分 | 値 | 補足 |
| --- | --- | --- |
| 外部の上限 | Python 3.12 系のサポート期限 2028-10 | セキュリティ修正の提供期限 |
| アプリの決定値 | Python 3.12 以上 | 構成要件で確定した実装言語 |

### 非機能要件テスト

なし。

実行ランタイムの判定は起動時チェックの単体テストで扱うため、非機能要件テストとしては持たない。
