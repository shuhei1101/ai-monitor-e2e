# タスク更新

エンドポイント: PATCH /tasks/{task_id}

登録済みタスクのタイトルと本文を更新し、更新後のタスクを返す。

- 対応テストファイル: -

## インターフェース

### リクエスト

| パラメータ | 型 | 必須 | デフォルト | 説明 | 制限 | 補足 |
| --- | --- | --- | --- | --- | --- | --- |
| `task_id` | str | ✅ | - | 更新対象のタスク ID | - | パスパラメータ |
| `title` | str | ✅ | - | 更新後のタイトル | 1 文字以上 100 文字以内 | 空白のみの文字列も文字数で数える |
| `content` | str | - | なし（更新前の本文を維持） | 更新後の本文 | 1000 文字以内 | 空文字を明示指定すると本文を消せる |

リクエスト例:

```json
{
  "title": "決算資料の作成",
  "content": "四半期の売上を集計する"
}
```

### レスポンス

| フィールド | 型 | 説明 | 制限 | 補足 |
| --- | --- | --- | --- | --- |
| `task` | object | 更新後のタスク | - | - |
| `task.id` | str | タスク ID | - | リクエストの `task_id` と一致する |
| `task.title` | str | 更新後のタイトル | - | - |
| `task.content` | str | 更新後の本文 | - | `content` 省略時は更新前の値 |

レスポンス例:

```json
{
  "task": {
    "id": "task_01",
    "title": "決算資料の作成",
    "content": "四半期の売上を集計する"
  }
}
```

**補足:**
- 同じリクエストを繰り返しても結果は変わらない（冪等）

### ステータスコード

| ステータスコード | 発生条件 | 補足 |
| --- | --- | --- |
| `200` | 更新成功 | - |
| `400` | リクエストのバリデーション失敗 | `title` / `content` が制限違反 |
| `404` | `task_id` のタスクが存在しない | - |

## 制約

| 項目 | 制約 | 補足 |
| --- | --- | --- |
| タイムアウト | 制限なし | インメモリのタスクストアのみを触るため待ちが発生しない |
| 認可 | 制限なし | 認証機構を持たないため誰でも更新できる |
| レート制限 | 制限なし | - |
| 応答時間 | 1 秒以内 | Issue #1614 の非機能要件 |
| 更新対象フィールド | `title` / `content` のみ | `task.id` は更新できない |

## フロー一覧

| 分類 | フロー名 | 概要 | 補足 |
| --- | --- | --- | --- |
| 正常 | 正常系 | タイトルと本文を更新して更新後のタスクを返す | - |
| 正常 | 正常系（本文の省略時） | 更新前の本文を維持してタイトルだけ更新する | - |
| 異常 | 異常系（タイトルが制限外・400） | 空 or 100 文字超を検証で弾いて 400 を返す | - |
| 異常 | 異常系（本文が制限外・400） | 1000 文字超を検証で弾いて 400 を返す | - |
| 異常 | 異常系（タスクが存在しない・404） | 未登録の `task_id` で 404 を返す | - |

## 正常系

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | タスクストアをインメモリの stub に差し替え | - |
| タスク | `task_01` をタイトル・本文とも設定済みで登録 | 更新前後の差分を見るため |

### フロー

```mermaid
sequenceDiagram
  participant C as クライアント
  participant IF as PATCH /tasks/｛task_id｝
  participant ST as タスクストア

  C->>IF: task_id, title, content
  IF->>IF: タイトルと本文の長さを検証
  IF-->>ST: task_id でタスクを取得
  IF->>IF: 取得したタスクに<br>title と content を反映
  IF->>ST: 更新後のタスクを保存
  IF-->>C: 200 OK<br>更新後のタスク
```

### 期待値

- `200` + 更新後のタスクが返る
- タスクストアの `task_01` がリクエストのタイトルと本文で置き換わっている

## 正常系（本文の省略時）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | タスクストアをインメモリの stub に差し替え | - |
| タスク | `task_01` を本文ありで登録 | 維持されることを確認するため |
| 入力 | `content` を省略して送信 | 本文維持の分岐を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  participant C as クライアント
  participant IF as PATCH /tasks/｛task_id｝
  participant ST as タスクストア

  C->>IF: task_id, title
  IF->>IF: タイトルの長さを検証
  IF-->>ST: task_id でタスクを取得
  IF->>IF: 本文は取得したタスクの値を引き継ぐ
  IF->>ST: 更新後のタスクを保存
  IF-->>C: 200 OK<br>更新後のタスク
```

### 期待値

- `200` + `task.content` が更新前の本文のまま返る
- タスクストアの `task_01` はタイトルだけが置き換わっている

## 異常系（タイトルが制限外・400）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | タスクストアをインメモリの stub に差し替え | - |
| タスク | `task_01` を登録済み | - |
| 入力 | `title` を空文字にして送信 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  participant C as クライアント
  participant IF as PATCH /tasks/｛task_id｝
  participant ST as タスクストア

```

### 期待値

- タスクストアの `task_01` は更新されていない

## 異常系（タスクが存在しない・404）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | タスクストアをインメモリの stub に差し替え | - |
| タスク | 登録なし | 取得失敗を決定的に誘発 |
| 入力 | 未登録の `task_id` で送信 | - |

### フロー

```mermaid
sequenceDiagram
  participant C as クライアント
  participant IF as PATCH /tasks/｛task_id｝
  participant ST as タスクストア

  C->>IF: 未登録の task_id, title
  IF->>IF: タイトルの長さを検証
  IF-->>ST: task_id でタスクを取得
  IF->>IF: 取得できず
  IF-->>C: 404 task_not_found
```

### 期待値

- `404` + `task_not_found` が返る
- タスクストアに新しいタスクは作られていない
