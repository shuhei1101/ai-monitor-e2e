# タスク一覧画面

画面: `src/screens/task_list.py`
モック: `docs/mock/pages/task-list/issues/1069/existing/`

登録されているタスクを一覧表示する画面。
本サブシステムでは、タスク編集画面で保存した内容が反映された状態を確認できる戻り先として、一覧の表示までを確定する。
一覧から編集画面へ遷移する導線は別サブシステム #1079（PR #1083）の担当のため、本ページでは行の選択時の処理を持たない。
バックエンドと同じ Python 実行環境の画面層として実装するため、要素は HTML のタグではなく画面層が組み立てる表示要素として定義する。

## 要素一覧

| 要素 | 種類 | 位置 | 説明 | 表示条件 | 必須 | 制限 | 初期値 | 取得元 | アクション | 補足 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 画面見出し | label | ヘッダー | 画面名を示す | 常時 | - | - | `タスク一覧` | - | - | - |
| タスク表 | table | 本体 | 取得したタスクを 1 行 1 件で並べる | 取得件数が 1 件以上のとき | - | 件数上限なし | 取得結果の全件（識別子の昇順） | `タスク一覧取得`（戻り値） | - | 表示項目は ※1 |
| 識別子見出し | label | 表ヘッダー | 識別子列の見出し | タスク表の表示時 | - | - | `ID` | - | - | - |
| タイトル見出し | label | 表ヘッダー | タイトル列の見出し | タスク表の表示時 | - | - | `タイトル` | - | - | - |
| タスク行 | row | 表本体 | タスク 1 件を表す行 | タスク表の表示時 | - | - | - | - | 本サブシステムでは選択時の処理を持たない | 選択時の処理は ※2 |
| 識別子セル | label | 表本体 | タスクの識別子 | タスク表の表示時 | - | - | 取得値 | `タスク一覧取得.[].id` | - | - |
| タイトルセル | label | 表本体 | タスクのタイトル | タスク表の表示時 | - | - | 取得値 | `タスク一覧取得.[].title` | - | 保存した内容の反映はここで確認する（※3） |
| 空状態メッセージ | label | 本体 | 登録が 0 件であることを示す | 取得件数が 0 件のとき | - | - | `タスクがありません` | - | - | 0 件でも画面が成立することを担保する |

※1: 表示項目は識別子・タイトルの 2 列にする（別サブシステム #1079 / PR #1083 の同名ページと同一）。
本文（`content`）は列に持たない。
採用モックの一覧にも本文の列がなく、列を足すと epic #1069 の横断要件「一覧画面のレイアウトは変更しない」に反するため。
編集画面へ遷移する導線を持たないため、行の選択で使う値（識別子）は表示のみに使う。

※2: タスク行の選択時の処理（遷移先の決定・`タスク詳細取得` の呼び出し・初期表示値の引き渡し・未検出メッセージの表示）は別サブシステム #1079（PR #1083）の担当範囲。
本ページでは要素の設置までを確定し、選択時の挙動と未検出メッセージの要素は定義しない。
PR #1083 の同名ページが未検出メッセージを含む形で同じ画面を定義しており、master へ集約する際は PR #1083 側の要素一覧が本ページを包含する。

※3: 単一 UC シナリオ「正常シナリオ」の期待値「一覧の対象タスクの行に、変更後のタイトル・本文が表示されている」のうち、行で確認できるのは変更後のタイトルまでになる。
変更後の本文は、同シナリオのもう 1 つの期待値「対象タスクのタイトル・本文が変更後の値で永続化されている」を保管先の値で確認することで担保する。

## 補足

- 一覧の取得元となる `タスク一覧取得` は本サブシステムの担当範囲外で、本 PR の base にもまだ入っていない。
  画面側は依存の関数型として受け取る形にして、取得元が入るまでは差し替えた関数で設計・テストを進める。
- 画面見出し・タスク表・識別子見出し・タイトル見出し・タスク行・識別子セル・タイトルセル・空状態メッセージの 8 要素は PR #1083 と同一定義にする（ブランチ系列が別で成果物が合流しないため意図的に重複させており、master へ集約する際に同内容として解消できる状態にする）。
