# タスク一覧画面

画面: `src/screens/task_list.py`
モック: `docs/mock/pages/task-list/issues/1069/existing/`

登録されているタスクを一覧表示し、任意のタスク行を選択してそのタスクの編集画面へ遷移する画面。
バックエンドと同じ Python 実行環境の画面層として実装するため、要素は HTML のタグではなく画面層が組み立てる表示要素として定義する。

## 要素一覧

| 要素 | 種類 | 位置 | 説明 | 表示条件 | 必須 | 制限 | 初期値 | 取得元 | アクション | 補足 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 画面見出し | label | ヘッダー | 画面名を示す | 常時 | - | - | `タスク一覧` | - | - | - |
| タスク表 | table | 本体 | 取得したタスクを 1 行 1 件で並べる | 取得件数が 1 件以上のとき | - | 件数上限なし | 取得結果の全件（識別子の昇順） | `タスク一覧取得`（戻り値） | - | 表示項目は ※1 |
| 識別子見出し | label | 表ヘッダー | 識別子列の見出し | タスク表の表示時 | - | - | `ID` | - | - | - |
| タイトル見出し | label | 表ヘッダー | タイトル列の見出し | タスク表の表示時 | - | - | `タイトル` | - | - | - |
| タスク行 | row | 表本体 | タスク 1 件を表す行 | タスク表の表示時 | - | - | - | - | 選択でそのタスクの編集画面へ遷移 | 行そのものが導線。行内に編集ボタン・リンクアイコン等の要素を置かない |
| 識別子セル | label | 表本体 | タスクの識別子 | タスク表の表示時 | - | - | 取得値 | `タスク一覧取得.[].id` | - | 遷移先の決定で引き渡す値と同じ |
| タイトルセル | label | 表本体 | タスクのタイトル | タスク表の表示時 | - | - | 取得値 | `タスク一覧取得.[].title` | - | - |
| 空状態メッセージ | label | 本体 | 登録が 0 件であることを示す | 取得件数が 0 件のとき | - | - | `タスクがありません` | - | - | 0 件でも画面が成立することを担保する |
| 未検出メッセージ | label | 本体 | 選択したタスクの詳細を取得できなかったことを示す | 直前の行選択で詳細取得が失敗したとき | - | - | `タスクが見つかりません` | - | - | 表示条件と遷移の扱いは ※2 |

※1: 表示項目は識別子・タイトルの 2 列にする。
モックには `状態` / `更新日` の列があるが、`タスク一覧取得` の戻り値（`id` / `title` / `content`）に対応するフィールドがなく、載せるには兄弟 subsystem #1073 のインターフェース変更が必要になるため本画面では持たない。
本文（`content`）は編集画面の初期表示値としてのみ使い、一覧には出さない（モックの一覧にも本文の列がない）。

※2: `タスク詳細取得` が「タスクが見つからない」の例外・「識別子の形式が不正」の例外のいずれを送出した場合も本メッセージを表示する。
このとき編集画面へは遷移せずタスク一覧画面に留まり、タスク表は一覧を取得し直した内容で表示し直す（削除済みタスクの行が残り続け、同じ操作が繰り返し失敗するのを避けるため）。
