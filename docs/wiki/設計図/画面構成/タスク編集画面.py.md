# タスク編集画面

画面: `src/screens/task_edit.py`
モック: `docs/mock/pages/task-edit/issues/1069/a-single-column/`

登録済みのタスクのタイトル・本文を編集する画面。
本サブシステムでは、編集内容を保存せずにタスク一覧画面へ戻る「編集の中止」の導線と、その判断に必要な入力欄・初期表示までを確定する。
バックエンドと同じ Python 実行環境の画面層として実装するため、要素は HTML のタグではなく画面層が組み立てる表示要素として定義する。

## 要素一覧

| 要素 | 種類 | 位置 | 説明 | 表示条件 | 必須 | 制限 | 初期値 | 取得元 | アクション | 補足 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 画面見出し | label | ヘッダー | 画面名を示す | 常時 | - | - | `タスク編集` | - | - | - |
| タイトル入力欄 | input | フォーム本体 | 編集対象のタスクのタイトルを入力 | 常時 | ✅ | 1〜100 文字 | 取得値 | `タスク詳細取得.title` | - | 必須の扱いは ※1 |
| 本文入力欄 | textarea | フォーム本体 | 編集対象のタスクの本文を入力 | 常時 | - | 1000 文字以内 | 取得値（本文が未設定なら空文字） | `タスク詳細取得.content` | - | - |
| 保存ボタン | button | フォーム本体下部 | 入力内容でタスクを更新 | 常時 | - | - | `保存` | - | 本サブシステムでは押下時の処理を持たない | 押下時の処理は ※1 |
| 編集の中止ボタン | button | フォーム本体下部 | 入力内容を保存せずに一覧画面へ戻る | 常時 | - | - | `編集の中止` | - | クリックで入力変更の有無を判定し、変更ありなら破棄確認ダイアログを表示・変更なしならタスク一覧画面へ遷移 | 判定対象は ※2 / 遷移先は ※3 |
| 破棄確認ダイアログ | dialog | 画面前面 | 入力内容を破棄してよいかを確認する | 変更がある状態で編集の中止ボタンを押したとき | - | - | 非表示 | - | - | キーボード操作は ※4 |
| 破棄確認メッセージ | label | 破棄確認ダイアログ | 破棄の可否を問う文言 | 破棄確認ダイアログの表示時 | - | - | `編集内容を破棄してタスク一覧へ戻りますか？` | - | - | - |
| 戻るボタン | button | 破棄確認ダイアログ | 入力内容を破棄して一覧画面へ戻る | 破棄確認ダイアログの表示時 | - | - | `戻る` | - | クリックで入力内容を破棄してタスク一覧画面へ遷移 | 更新操作は呼ばない。遷移先は ※3 |
| 編集を続けるボタン | button | 破棄確認ダイアログ | 編集画面に留まる | 破棄確認ダイアログの表示時 | - | - | `編集を続ける` | - | クリックでダイアログを閉じ、入力内容を保持したまま編集画面に留まる | - |

※1: 保存ボタン押下時の処理（更新操作の呼び出し・タイトル必須チェックとエラー表示・保存後の遷移）は兄弟 story #1075 の担当範囲。
本サブシステムでは要素の設置までを確定し、押下時の挙動と必須エラーの表示要素は定義しない。
タイトル入力欄の必須・制限列は `タスク詳細取得` が返す値が満たす範囲に合わせた表示上の前提で、入力値の検証内容は #1075 側で確定する。
モックにある本文欄の補助文言（本文が空でも保存できる旨）も保存側の確定と合わせて #1075 で定義する。

※2: 変更の有無はタイトル入力欄・本文入力欄の 2 要素について、初期値（`タスク詳細取得` が返した値）と現在の入力値をそれぞれ文字列として比較して判定する。
前後の空白の除去などの正規化は行わず、いずれか 1 つでも一致しなければ変更ありとする。

※3: 遷移先はタスク一覧画面（画面識別子 `task-list`）で、遷移時に引き渡す値は持たない。
編集画面・一覧画面の URL 形式は別 subsystem #1079 が確定するため、本ページでは新規に定義しない。

※4: 破棄確認ダイアログは「戻る」「編集を続ける」の両方をキーボード操作で選択できるようにする。
ダイアログの表示中は背後の入力欄を操作対象にしない。
