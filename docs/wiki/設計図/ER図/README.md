# ER 図

プロジェクトのデータストア構造の索引ページ。
詳細は各分類別ファイルへ。

論理名（業務語彙）はドキュメント・口頭で、物理名（snake_case）は実装で使う。
両者の対応は本ページと各分類別ファイルでのみ正規化して管理する。

## 概要

主データストア:

- インメモリストア（`dict[str, Task]`）: タスク ドメイン

プロセスのメモリ上にのみ保持し、永続化は行わない。
論理名は日本語、物理名は `snake_case` で統一。
作成日時・更新日時の共通カラムは持たない。

## 全体図

    str ID PK
    str タイトル

  }
