# タスク編集

登録済みタスクのタイトルと本文を書き換えて保存する単一ユースケース。

- 対応テストファイル: `tests/e2e/単一ユースケース/test_タスク編集.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスクストア | 編集対象のタスクを 1 件登録済みのストア | `Task(id="t1", title="旧タイトル", content="旧本文")` |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant CALLER as 呼び出し元
  participant SVC as タスクサービス
  participant STORE as タスクストア

  U->>CALLER: 一覧を開く
  CALLER->>STORE: list_tasks でストアを走査
  STORE-->>CALLER: ID 順に並べたタスク一覧
  CALLER-->>U: 一覧を提示
  U->>CALLER: 対象タスクの ID と<br>編集後のタイトル・本文を渡す
  CALLER->>SVC: update_task（ID・タイトル・本文）
  SVC->>SVC: タイトル長を検証（1〜100 文字）
  SVC->>SVC: 本文長を検証（1000 文字以内）
  SVC->>STORE: get_task で対象タスクを取得
  STORE-->>SVC: 編集前のタスク
  SVC->>STORE: 同じ ID で作り直したタスクを書き戻す
  SVC-->>CALLER: 編集後のタスク
  CALLER->>STORE: list_tasks で一覧を取り直す
  STORE-->>CALLER: 編集後の内容を含む一覧
  CALLER-->>U: 編集後の一覧を提示
```

### 期待値

- `update_task` の戻り値のタイトルと本文が編集後の値になっている
- `list_tasks` の結果に編集後のタイトルと本文が並んでいる
- 編集後のタスクの ID が編集前と同じ

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスクストア | 編集対象のタスクを 1 件登録済みのストア | `Task(id="t1", title="旧タイトル", content="旧本文")` |
| 入力 | タイトルを空にして保存 | `title=""`（下限 1 文字を下回らせて検証失敗を誘発） |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant CALLER as 呼び出し元
  participant SVC as タスクサービス
  participant STORE as タスクストア

  U->>CALLER: タイトルを空にして保存
  CALLER->>SVC: update_task（ID・空タイトル）
  SVC->>SVC: タイトル長を検証して失敗
  SVC-->>CALLER: ValidationError を送出
  CALLER-->>U: 例外がそのまま伝播
  U->>CALLER: 一覧を開き直す
  CALLER->>STORE: list_tasks でストアを走査
  STORE-->>CALLER: 編集前のままの一覧
  CALLER-->>U: 編集前の一覧を提示
```

### 期待値

- `ValidationError` が送出される
- `list_tasks` の結果が編集前のタイトルと本文のまま

sequenceDiagram
