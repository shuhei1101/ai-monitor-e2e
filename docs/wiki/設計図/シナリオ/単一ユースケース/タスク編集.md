# タスク編集

ログイン中ユーザーが一覧からタスクを選択し、内容を編集して保存する単一ユースケース。

- 対応テストファイル: `tests/e2e/単一ユースケース/タスク編集.spec.ts`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| `createUser` | ログイン中ユーザー A | - |
| `createTask` | userA が所有する編集対象タスク | `title: 旧タイトル` |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API
  participant DB as DB

  U->>FE: タスク一覧画面を開く
  FE->>BE: GET /tasks
  BE->>DB: 一覧取得
  BE-->>FE: タスク一覧を返却
  FE-->>U: 一覧を表示
  U->>FE: 対象タスク行を選択
  FE->>BE: GET /tasks/{id}
  BE->>DB: 対象タスク取得
  BE-->>FE: 初期値を返却
  FE-->>U: 編集画面に遷移し初期値を表示
  U->>FE: タイトル・内容を編集して保存
  FE->>FE: 入力バリデーション（OK）
  FE->>BE: PUT /tasks/{id}
  BE->>DB: 更新
  BE-->>FE: 200 OK
  FE-->>U: 一覧画面に戻り 3 秒トーストで保存成功を通知
```

### 期待値

- 一覧画面の対象行が編集後の内容で表示されている
- DB の該当タスクレコードが編集後の値になっている
- 保存成功トーストが表示され、3 秒後に自動的に消える

## 異常シナリオ（必須フィールド未入力）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| `createUser` | ログイン中ユーザー A | - |
| `createTask` | userA が所有する編集対象タスク | `title: 旧タイトル` |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API

  U->>FE: 一覧から対象タスクを選択して編集画面へ遷移
  FE->>BE: GET /tasks/{id}
  BE-->>FE: 初期値を返却
  FE-->>U: 編集画面を表示
  U->>FE: タイトルを空にして保存
  FE->>FE: 入力バリデーション失敗
  FE-->>U: タイトル欄直下にインラインエラーを表示
```

### 期待値

- タイトルフィールド直下にインラインエラー（必須メッセージ）が表示されている
- 保存 API（PUT /tasks/｛id｝）は呼ばれていない
- DB の該当タスクレコードが編集前の値のまま
- 保存成功トーストは表示されない

## 異常シナリオ（他ユーザー所有タスクの編集を試みる）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| `createUser` | ログイン中ユーザー A | - |
| `createUser` | 他人ユーザー B | - |
| `createTask` | userB が所有するタスク | 編集対象外 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API
  participant DB as DB

  U->>FE: 他ユーザー B のタスク編集 URL に直アクセス
  FE->>BE: GET /tasks/{他ユーザー id}
  BE-->>FE: 403 Forbidden
  FE-->>U: 403 画面に遷移
```

### 期待値

- 403 画面が表示されている
- DB の userB 所有タスクレコードが変更されていない
