# タスク編集

一覧から選んだタスクの内容を編集して保存する単一ユースケース。

- 対応テストファイル: `tests/e2e/単一ユースケース/test_タスク編集.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | タイトル・本文とも初期値あり |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API
  participant DB as DB

  U->>FE: 一覧から対象タスクを選ぶ
  FE->>BE: 対象タスクの取得
  BE-->>DB: タスク取得
  BE-->>FE: 編集前のタイトル・本文
  FE-->>U: 編集画面に初期値を表示
  U->>FE: タイトルと本文を編集して保存
  FE->>FE: 入力検証（タイトル必須）
  FE->>BE: タスク更新
  BE->>DB: 更新
  BE-->>FE: 更新後のタスク
  FE-->>U: 一覧へ戻り 完了トーストを表示
```

### 期待値

- 一覧に編集後のタイトルと本文が表示されている
- 完了トーストが表示されている
- 保存されたタスクのタイトル・本文が編集後の値になっている

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | - |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API

  U->>FE: 一覧から対象タスクを選ぶ
  FE->>BE: 対象タスクの取得
  BE-->>FE: 編集前のタイトル・本文
  FE-->>U: 編集画面に初期値を表示
  U->>FE: タイトルを空にして保存
  FE->>FE: 入力検証で失敗
  FE-->>U: タイトル欄の直下に<br>インラインエラーを表示
```

### 期待値

- タイトル欄の直下にインラインエラーが表示されている
- 一覧のタスクが編集前のタイトル・本文のまま変わっていない
