# タスク編集

ユーザーが一覧から選んだタスクの内容を編集して保存する単一ユースケース。

- 対応テストファイル: `tests/e2e/単一ユースケース/test_タスク編集.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | タイトル・本文とも入力済み |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API
  participant STORE as インメモリストア

  U->>FE: 一覧画面で編集対象のタスクを選ぶ
  FE-->>BE: 対象タスクの内容を取得
  BE-->>STORE: 対象タスクを参照
  BE-->>FE: 現在のタイトルと本文を返す
  FE-->>U: 編集画面に初期値を表示
  U->>FE: タイトルと本文を書き換えて保存
  FE->>FE: 入力検証（タイトルが空でないこと）
  FE->>BE: 編集内容の保存を要求
  BE->>STORE: 対象タスクを更新
  BE-->>FE: 保存完了を返す
  FE-->>U: 一覧へ戻り<br>保存成功のトーストを表示
```

### 期待値

- 一覧に編集後のタイトルと本文が表示されている
- 保存成功のトーストが表示されている
- ストアの対象タスクが編集後のタイトルと本文になっている

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | タイトル・本文とも入力済み |
| 入力 | 編集画面でタイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as 画面（フロントエンド）
  participant BE as バックエンド API
  participant STORE as インメモリストア

  U->>FE: 一覧画面で編集対象のタスクを選ぶ
  FE-->>BE: 対象タスクの内容を取得
  BE-->>STORE: 対象タスクを参照
  BE-->>FE: 現在のタイトルと本文を返す
  FE-->>U: 編集画面に初期値を表示
  U->>FE: タイトルを空にして保存
  FE->>FE: 入力検証で失敗
  FE-->>U: タイトル欄の直下にエラーを表示
```

### 期待値

- タイトル欄の直下にエラーが表示され、編集画面に留まっている
- 一覧が編集前のタイトルと本文のまま変わっていない
- ストアの対象タスクが編集前のタイトルと本文のまま
