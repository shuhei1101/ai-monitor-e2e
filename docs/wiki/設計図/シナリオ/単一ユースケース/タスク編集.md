# タスク編集

一覧から選択したタスクの内容を編集して保存する単一ユースケース。

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 編集対象のタスクを 1 件登録済み | - |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面
  participant BE as バックエンド API
  participant AB as 承認基盤

  Note over U,AB: 受付完了で一覧へ戻る
  U->>FE: 内容を編集して保存
  FE->>BE: タスク更新リクエスト
  BE->>AB: 更新の承認を依頼
  BE-->>FE: 受付完了
  FE-->>U: 一覧へ戻り 完了トースト表示

  Note over U,AB: 承認確定後に一覧へ反映される
  AB-->>BE: 更新の確定
  BE->>BE: タスクを編集後の内容へ更新
  U->>FE: 一覧を表示
  FE->>BE: タスク一覧リクエスト
  BE-->>FE: 編集後のタスク
  FE-->>U: 編集後の内容を表示
```

### 期待値

- 受付完了の直後は、一覧が編集前の内容のままである
- 承認確定後は、一覧が編集後の内容へ反映される

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面

  U->>FE: タイトルを空にして保存
  FE->>FE: 入力バリデーション失敗
  FE-->>U: インラインエラー表示
```

### 期待値

- インラインエラーが表示され、保存されていない
