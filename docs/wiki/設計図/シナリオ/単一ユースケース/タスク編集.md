# タスク編集

一覧から選択したタスクの内容を編集して保存する単一ユースケース。
保存操作は更新の受け付けで完了し、外部の承認基盤から結果が返った時点で内容が確定する。

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | 承認基盤（承認結果を任意のタイミングで返すスタブ） | 非同期の応答を決定的に起こすため |
| タスク | 編集対象のタスクを 1 件登録済み | 承認済みの状態 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面
  participant LIST as タスク一覧画面
  participant BE as バックエンド API
  participant AP as 承認基盤

  U->>FE: 内容を編集して保存
  FE->>BE: タスク更新リクエスト
  BE->>AP: 更新内容の承認依頼
  AP-->>BE: 依頼の受付応答
  BE-->>FE: 受け付け応答（承認待ち）
  FE-->>U: 一覧へ戻り 受付トースト表示
  LIST-->>U: 該当タスクを承認待ちとして表示
  AP-->>BE: 承認結果（承認）
  BE->>BE: タスクを編集後の内容で確定
  U->>LIST: 一覧を再表示
  LIST-->>U: 承認待ちの表示を消し 編集後の内容を表示
```

### 期待値

- 保存直後の一覧に、編集後の内容が承認待ちとして表示されている
- 承認待ちの間は該当タスクの編集導線が無効になっている
- 承認結果が返った後の一覧では承認待ちの表示が消え、編集後の内容が確定して表示されている

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面

  U->>FE: タイトルを空にして保存
  FE->>FE: 入力バリデーション失敗
  FE-->>U: インラインエラー表示
```

### 期待値

- インラインエラーが表示され、保存されていない

## 異常シナリオ（承認が否認される）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | 承認基盤（否認の結果を返すスタブ） | 否認を決定的に誘発 |
| タスク | 編集対象のタスクを 1 件登録済み | 承認済みの状態 |
| 操作 | 内容を編集して保存済み | 承認待ちの状態から開始 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant LIST as タスク一覧画面
  participant BE as バックエンド API
  participant AP as 承認基盤

  AP-->>BE: 承認結果（否認）
  BE->>BE: タスクを編集前の内容へ戻し 否認を記録
  U->>LIST: 一覧を再表示
  LIST-->>U: 編集前の内容と否認の通知を表示
  U->>LIST: 否認の通知を確認
  LIST-->>U: 通知を消し 編集できる状態に戻す
```

### 期待値

- 一覧の該当タスクが編集前の内容に戻っている
- 一覧の該当タスクに否認の通知が表示されている
- 通知を確認すると通知が消え、該当タスクを再び編集できる

## 異常シナリオ（承認待ちのタスクを再度編集）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | 承認基盤（結果を返さないスタブ） | 承認待ちの状態を保持 |
| タスク | 編集対象のタスクを 1 件登録済み | 承認済みの状態 |
| 操作 | 内容を編集して保存済み | 承認待ちの状態から開始 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant LIST as タスク一覧画面
  participant BE as バックエンド API

  U->>LIST: 承認待ちのタスクの編集を試みる
  LIST-->>U: 編集導線が無効で 承認待ちである旨を表示
  Note over LIST,BE: 更新リクエストは送られない
```

### 期待値

- 編集導線が無効で、承認待ちである旨が表示される
- 承認基盤へ二重の承認依頼が送られていない
