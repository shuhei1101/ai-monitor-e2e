# タスク編集

一覧から選択したタスクの内容を編集して保存し、更新の申請として受け付けられる単一ユースケース。

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 編集対象のタスクを 1 件登録済み | - |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面
  participant BE as バックエンド API

  U->>FE: 内容を編集して保存
  FE->>BE: タスク更新リクエスト
  BE-->>FE: 更新受付完了
  FE-->>U: 一覧へ戻り 受付完了トースト表示
  FE-->>U: 対象タスクを申請中として表示
```

### 期待値

- 一覧に対象タスクが申請中として表示されている

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
sequenceDiagram
  actor U as ユーザー
  participant FE as タスク編集画面

  U->>FE: タイトルを空にして保存
  FE->>FE: 入力バリデーション失敗
  FE-->>U: インラインエラー表示
```

### 期待値

- インラインエラーが表示され、保存されていない
