# タスク編集から一覧反映

現状の実装から起こした複合 UC。

- 対応テストファイル: `tests/e2e/複合ユースケース/test_タスク編集から一覧反映.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | タイトル・本文とも編集前の値 |

### フロー

```mermaid
flowchart TD
  A([ユーザー]) -->|一覧から対象タスクを選び 編集画面を開く| UC1([タスク編集:正常シナリオ])
  UC1 -->|保存済みのタスクを一覧が読み直す| S1([一覧に編集後のタイトルと本文が並んだ状態])

  click UC1 "../単一ユースケース/タスク編集.md#正常シナリオ"
```

### 期待値

- 一覧に編集後のタイトルと本文が並んでいる

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスク | 一覧に表示される編集対象のタスクを 1 件登録済み | タイトル・本文とも編集前の値 |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
flowchart TD
  A([ユーザー]) -->|一覧から対象タスクを選び タイトルを空にして保存| UC1([タスク編集:異常シナリオ<br>（タイトルが空）])
  UC1 -->|保存されないまま一覧に戻る| S1([一覧が編集前のタイトルと本文のままの状態])

  click UC1 "../単一ユースケース/タスク編集.md#異常シナリオタイトルが空"
```

### 期待値

- 一覧のタスクが編集前のタイトルと本文のまま並んでいる
