# タスク編集から一覧反映

現状の実装から起こした複合 UC。
タスクを編集して保存し、一覧に反映されるまでを扱う。

- 対応テストファイル: `tests/e2e/複合ユースケース/test_タスク編集から一覧反映.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスクストア | 編集対象のタスクを 1 件だけ持つストア | `id: t1` / `title: 旧タイトル` / `content: 旧本文` |

### フロー

```mermaid
flowchart TD
  subgraph FOCUS["検証対象: 保存したタスクが一覧の表示に引き継がれるか"]
    UC1([タスク編集:正常シナリオ]) -->|更新後のタスクをストアへ書き戻し・一覧を開く| UC2([タスク一覧:正常シナリオ])
  end

  U1([ユーザー]) -->|タスクのタイトルと本文を書き換えて保存| UC1
  UC2 --> S1([一覧に編集後のタイトルと本文が並んだ状態])

  click UC1 "../単一ユースケース/タスク編集.md#正常シナリオ"
  click UC2 "../単一ユースケース/タスク一覧.md#正常シナリオ"
```

### 期待値

- 一覧に編集後のタイトルと本文が並んでいる

## 異常シナリオ（タイトルが空）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| タスクストア | 編集対象のタスクを 1 件だけ持つストア | `id: t1` / `title: 旧タイトル` / `content: 旧本文` |
| 入力 | タイトルを空にして保存 | 検証失敗を決定的に誘発 |

### フロー

```mermaid
flowchart TD
  subgraph FOCUS["検証対象: 保存が弾かれたときに一覧が編集前のまま保たれるか"]
    UC3([タスク編集:異常シナリオ<br>（タイトルが空）]) -->|保存されないまま一覧を開く| UC4([タスク一覧:正常シナリオ])
  end

  U2([ユーザー]) -->|タイトルを空にして保存| UC3
  UC4 --> S2([一覧が編集前のタイトルと本文のままの状態])

  click UC3 "../単一ユースケース/タスク編集.md#異常シナリオタイトルが空"
  click UC4 "../単一ユースケース/タスク一覧.md#正常シナリオ"
```

### 期待値

- 一覧のタスクが編集前のタイトルと本文のまま
