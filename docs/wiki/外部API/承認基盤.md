## POST `/approvals`

更新内容の承認を依頼し、受付できたかどうかの応答を得る。

### リクエスト

| パラメータ | 型 | 必須 | デフォルト | 説明 | 制限 | 補足 |
| --- | --- | --- | --- | --- | --- | --- |
| `target_id` | `str` | ✅ | - | 承認対象の識別子 | - | タスク ID を渡す |
| `title` | `str` | ✅ | - | 承認してほしいタイトル | 100 文字以内 | - |
| `content` | `str` | ✅ | - | 承認してほしい本文 | 1000 文字以内 | 本文なしの場合は空文字 |

リクエスト例:

```json
{
  "target_id": "t1",
  "title": "新タイトル",
  "content": "新本文"
}
```

### レスポンス

| フィールド | 型 | 説明 | 制限 | 補足 |
| --- | --- | --- | --- | --- |
| `accepted` | `bool` | 受付できたか | - | `false` のとき `rejected_reason` が入る |
| `acceptance_id` | `str` | 採番された受付 ID | - | `accepted` が `false` のときは空文字 |
| `rejected_reason` | `str` | 受付を拒否した理由 | - | `accepted` が `true` のときは空文字 |

レスポンス例:

```json
{
  "accepted": true,
  "acceptance_id": "ap_0001",
  "rejected_reason": ""
}
```

### ステータスコード

| ステータスコード | 発生条件 | 補足 |
| --- | --- | --- |
| `200` | 受付の可否が決まった | 拒否も `200` + `accepted: false` で返る |
