# テスト実行方法

本プロジェクトのテスト実行コマンドと前提条件。

## 前提

- Python 3.12 以上（標準ライブラリのみを使う。外部パッケージのインストールは不要）
- テストは `unittest` で書き、`tests/` 配下に実装のパスをミラーして置く
- テストの対応関係は設計書のテスト表が正本で、テストは表と 1:1 で実装する
- コマンドはリポジトリルート（`tests/` の親）で実行する

## ディレクトリ構成

```
tests/
├── unit/           # 単体テスト（src をミラー。1 テストファイル = 1 実装ファイル）
├── integration/    # 結合テスト（1 テストファイル = 1 操作）
└── e2e/            # シナリオ E2E テスト
```

## テストの単位と名前

| 種類 | ファイル | クラス | メソッド |
| --- | --- | --- | --- |
| 単体 | 実装ファイル 1 つ | 対象の関数・データモデル 1 つ | モジュール構成の単体テスト表の テスト名 |
| 結合 | 結合ドキュメント 1 ページ | 操作 1 つ | フロー名（`正常系` → `test_normal` / `正常系（{条件}）` → `test_normal_when_{条件}` / `異常系（{条件}）` → `test_error_when_{条件}`） |
| E2E | シナリオ 1 ページ | シナリオ 1 本 | シナリオ内のフロー名（結合と同じ変換規則） |

## 単体テスト（バックエンド）

対象は `設計図/モジュール構成/バックエンド/**` の各関数の単体テスト表。

前提:

- 外部依存なし（タスクの保管先はテスト内で辞書を直接構築する）

全件実行:

```bash
python3 -m unittest discover -s tests/unit -t .
```

個別ファイル実行:

```bash
python3 -m unittest tests.unit.tasks.test_service
```

個別メソッド実行:

```bash
python3 -m unittest tests.unit.tasks.test_service.UpdateTaskTest.test_update_task
```

## 単体テスト（フロントエンド）

対象は `設計図/モジュール構成/フロントエンド/**` の各関数の単体テスト表。

前提:

- 外部依存なし（画面層の関数は引数だけで結果が決まる）
- バックエンドの呼び出しを持つ関数（`open_task_edit` / `save_task` / `render_task_list`）は、注入する関数をテスト内で作って渡す

個別ファイル実行:

```bash
python3 -m unittest tests.unit.screens.test_task_edit
python3 -m unittest tests.unit.screens.test_task_list
python3 -m unittest tests.unit.screens.test_navigation
```

個別メソッド実行:

```bash
python3 -m unittest tests.unit.screens.test_task_edit.ValidateTitleTest.test_validate_title_when_blank
```

## 結合テスト（バックエンド）

対象は `設計図/バックエンド結合/**` の各フロー。

前提:

- 外部依存なし（タスクの保管先はテスト内で辞書を直接構築する）

全件実行:

```bash
python3 -m unittest discover -s tests/integration -t .
```

個別ファイル実行:

```bash
python3 -m unittest tests.integration.tasks.test_update_task
```

## 結合テスト（フロントエンド）

対象は `設計図/フロントエンド結合/**` の各フロー。
バックエンドと同じ `tests/integration/` 配下に置くため、全件実行のコマンドはバックエンドと共通。

前提:

- バックエンドの呼び出し（`タスク詳細取得` / `タスク更新` / `タスク一覧取得`）はテスト内で作った関数に差し替える

個別ファイル実行:

```bash
python3 -m unittest tests.integration.screens.test_task_edit_display
python3 -m unittest tests.integration.screens.test_save_task
```

## 単一ユースケース E2E テスト

対象は `設計図/シナリオ/単一ユースケース/タスク編集.md` の 3 シナリオ。
対応テストファイルは `tests/e2e/tasks/test_task_edit.py`。

前提:

- 画面（フロントエンド）とバックエンドの実装の両方が必要
- バックエンドの `get_task` / `update_task` / `list_tasks` が本ブランチの base に入るまで実行しない。
  揃うまでの間はテストの実装だけを進め、実行結果は「未実行（依存待ち）」として記録する

個別ファイル実行:

```bash
python3 -m unittest tests.e2e.tasks.test_task_edit
```

## 複合ユースケース E2E テスト

対象は `設計図/シナリオ/複合ユースケース/タスク編集の中止から再編集.md`。

前提:

- 単一ユースケース E2E テストと同じ前提に加えて、シナリオが通る `タスク編集の中止`（兄弟 story #1076 / subsystem #1081 の担当）の実装が必要
- 中止の実装は別ブランチ系列のため本ブランチには入らない。
  揃うまで実行せず、実行結果は「未実行（依存待ち）」として記録する
