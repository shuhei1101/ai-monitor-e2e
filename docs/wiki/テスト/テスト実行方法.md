# テスト実行方法

本プロジェクトのテスト実行コマンドと前提条件。

## 前提

- Python 3.12 以上（標準ライブラリのみを使う。外部パッケージのインストールは不要）
- テストは `unittest` で書き、`tests/` 配下に実装のパスをミラーして置く
- テストの対応関係は設計書のテスト表が正本で、テストは表と 1:1 で実装する

## ディレクトリ構成

```
tests/
├── unit/           # 単体テスト（src をミラー。1 テストファイル = 1 実装ファイル）
├── integration/    # 結合テスト（1 テストファイル = 1 操作）
└── e2e/            # シナリオ E2E テスト
```

## 単体テスト（バックエンド）

対象は `設計図/モジュール構成/**` の各関数の単体テスト表。

前提:

- 外部依存なし（タスクの保管先はテスト内で辞書を直接構築する）

全件実行:

```bash
python3 -m unittest discover -s tests -t .
```

個別ファイル実行:

```bash
python3 -m unittest tests.unit.tasks.test_query
```

個別メソッド実行:

```bash
python3 -m unittest tests.unit.tasks.test_query.GetTaskTest.test_get_task
```

## 結合テスト（バックエンド）

対象は `設計図/バックエンド結合/**` の各フロー。

全件実行:

```bash
python3 -m unittest discover -s tests/integration -t .
```

## 単一ユースケース E2E テスト

対象は `設計図/シナリオ/単一ユースケース/**` の各シナリオ。
実行には画面（フロントエンド）が必要なため、フロントエンドの実装が入るまでは実行しない。

## 複合ユースケース E2E テスト

なし
