# テスト実行方法

本プロジェクトのテスト実行コマンドと前提条件。

## 前提

- Python 3.12 以上（標準ライブラリのみを使う。外部パッケージのインストールは不要）
- テストは `unittest` で書き、`tests/` 配下に実装のパスをミラーして置く
- テストの対応関係は設計書のテスト表が正本で、テストは表と 1:1 で実装する

## ディレクトリ構成

```
tests/
├── unit/           # 単体テスト（src をミラー。1 テストファイル = 1 実装ファイル）
├── integration/    # 結合テスト（1 テストファイル = 1 操作）
└── e2e/            # シナリオ E2E テスト
```

## 単体テスト（バックエンド）

対象は `設計図/モジュール構成/**` の各関数の単体テスト表。

前提:

- 外部依存なし（タスクの保管先はテスト内で辞書を直接構築する）

全件実行:

```bash
python3 -m unittest discover -s tests -t .
```

個別ファイル実行:

```bash
python3 -m unittest tests.unit.tasks.test_query
```

個別メソッド実行:

```bash
python3 -m unittest tests.unit.tasks.test_query.GetTaskTest.test_get_task
```

## 単体テスト（フロントエンド）

対象は `設計図/モジュール構成/フロントエンド/**` の各関数の単体テスト表。

前提:

- 外部依存なし（画面層の関数は引数だけで結果が決まるため、差し替える依存を持たない）
- バックエンドの呼び出しを持つ画面層の関数は、注入する関数をテスト内で作って渡す

個別ファイル実行:

```bash
python3 -m unittest tests.unit.screens.test_task_edit
```

個別メソッド実行:

```bash
python3 -m unittest tests.unit.screens.test_task_edit.CancelEditTest.test_cancel_edit
```

## 結合テスト（バックエンド）

対象は `設計図/バックエンド結合/**` の各フロー。

全件実行:

```bash
python3 -m unittest discover -s tests/integration -t .
```

## 結合テスト（フロントエンド）

対象は `設計図/フロントエンド結合/**` の各フロー。
バックエンドと同じ `tests/integration/` 配下に置くため、全件実行のコマンドはバックエンドと共通。

個別ファイル実行:

```bash
python3 -m unittest tests.integration.screens.test_task_edit_cancel
```

## 単一ユースケース E2E テスト

対象は `設計図/シナリオ/単一ユースケース/**` の各シナリオ。
実行には画面（フロントエンド）が必要なため、フロントエンドの実装が入るまでは実行しない。

シナリオが複数の画面をまたぐ場合は、登場する全ての画面の実装が揃うまで実行しない。
揃うまでの間はテストの実装だけを進め、実行結果は「未実行（依存待ち）」として記録する。

## 複合ユースケース E2E テスト

対象は `設計図/シナリオ/複合ユースケース/**` の各シナリオ。
単一ユースケース E2E テストと同じ前提に加えて、シナリオが通る全てのユースケースの実装が揃うまで実行しない。
