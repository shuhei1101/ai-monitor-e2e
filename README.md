# タスク管理ツール

散らばったタスクを 1 か所に集めて、登録・編集・一覧できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリにタスクが散らばると未着手のものを見失う。
本ツールはタスクを 1 か所に集約し、登録したタスクの内容を後から編集し、残っているタスクを一覧で確認できるようにする。
想定利用者は 1 人（個人利用）。
