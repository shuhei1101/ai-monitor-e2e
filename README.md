# タスク管理ツール

登録したタスクを 1 か所で編集・確認できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリに散らばったタスクを 1 か所に集め、登録・編集・一覧を同じ場所で完結できるようにする。
未着手のタスクを見失わない状態を保つことが目的。
想定利用者は本人 1 人。
