# タスク管理ツール

タスクを登録して編集・一覧できる個人向けのツール。

## 概要

紙とメモアプリにタスクが散らばって未着手のものを見失う人向けに、タスクの登録・編集・一覧を 1 か所にまとめる。
登録済みのタスクをいつでも引き当てられるようにして、取りこぼしを防ぐ。
想定利用者は個人 1 人。
