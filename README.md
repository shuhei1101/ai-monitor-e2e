# タスク管理ツール

散らばったタスクを 1 か所に集めて、登録・編集・一覧できる個人向けのツール。

## 概要

紙とメモアプリにタスクが分散していて未着手のものを見失う状態を解消するために、タスクの登録・編集・一覧を 1 つのツールで完結させる。
想定利用者は個人 1 名。
