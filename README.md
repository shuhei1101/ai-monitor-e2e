# タスク管理ツール

タスクを登録して編集・一覧できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリに散らばったタスクを 1 箇所に集めて、未着手のものを見失わないようにする。
登録したタスクはタイトルと本文を後から編集でき、一覧で現状を確認できる。
想定利用者は個人 1 名。
