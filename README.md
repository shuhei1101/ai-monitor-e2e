# タスク管理ツール

散らばったタスクを 1 箇所に集めて、未着手のものを見失わないようにする個人向けのタスク管理ツール。

## 概要

紙とメモアプリに分散しているタスクを 1 つの置き場所にまとめ、登録・編集・一覧を同じ場所で完結できるようにする。
どのタスクが未着手のまま残っているかを、探し回らずに確認できる状態を目指す。

想定利用者は個人 1 名。
