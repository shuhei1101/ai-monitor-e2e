# タスク管理ツール

タスクを登録して編集・一覧できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリに散らばったタスクを 1 か所に集め、未着手のものを見失わないようにする。
登録したタスクはあとからタイトルと本文を編集でき、一覧でまとめて確認できる。
想定利用者は個人 1 名。
