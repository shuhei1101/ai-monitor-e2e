# タスク管理ツール

タスクを登録して編集・一覧できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリに散らばったタスクを 1 か所にまとめ、未着手のものを見失わないようにする。
タスクの登録・編集・一覧を通して、いま何が残っているかをその場で確認できる状態を目指す。
想定利用者は個人での利用を前提とする（複数人での同時利用は未確定）。
