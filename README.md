# タスク管理ツール

タスクを登録して編集・一覧できる個人向けのタスク管理ツール。

## 概要

紙とメモアプリに散らばったタスクを 1 か所に集め、登録・編集・一覧を通して未着手のものを見失わないようにする。
対象は個人利用で、想定規模は未確定。
